Aver

        
A language designed for AI to write and humans to review.


        

            

                Intent is explicit
                Every function can carry a prose description (?) explaining what and why.
            

            

                Effects are tracked
                I/O, network, disk — declared in the type system with ! [Console.print]. No hidden side effects.
            

            

                Verify blocks are specs
                verify add cases run as tests, act as documentation, guard against regressions.
            

            

                Multiple backends
                Bytecode VM for dev, Rust codegen for deploy, WASM for browsers. Same source, same semantics.
            

        


        
fn divide(a: Int, b: Int) -> Result<Int, String>
    ? "Safe division. Returns Err on zero."
    match b
        0 -> Result.Err("Division by zero")
        _ -> Result.Ok(a / b)

verify divide
    divide(10, 2) => Result.Ok(5)
    divide(10, 0) => Result.Err("Division by zero")

Native WASM

        
No emscripten. Shared runtime. Just your code.


        

            

                Direct compilation
                Aver has its own WASM codegen — it emits WebAssembly GC bytecode directly, not through Rust or C. No emscripten, no wasm-bindgen, no glue code. Engine handles GC and tail calls; the binary you ship is just your program logic plus per-instantiation helpers DCE'd to what each program actually calls.
            

            

                Tiny binaries
                Snake ships at 4.3 KiB. Tetris is 8.3 KiB. A full roguelike with procedural generation is 25.6 KiB. Built with --target wasm-gc --optimize size — engine GC + native tail-calls; per-program binary, no shared runtime to fetch.
            

            

                Capability-based imports
                WASM modules import only the effects they declare: Terminal.print, Console.readLine, Time.sleep. The host provides implementations. No filesystem access, no network — unless you grant it.
            

            

                Make your own
                Install Aver, compile to WASM, and drop the file here.
            

        


        
$ cargo install aver-lang
$ aver compile game.av --target wasm-gc --optimize size
Compiled game.av → game.wasm (5.0 KiB, engine GC + tail calls, imports aver/* (effects))

# drag game.wasm into the playground — modern browsers only
# (Chrome 119+ / Firefox 120+ / Safari 18.2+).
