## The load-bearing rewrite — body/emit.rs dispatch tree

The trickiest part of this PR (and the reason I deferred it) is the hand-coded dispatch in `body/emit.rs::emit_expr` at line 372:

```rust
Expr::FnCall(callee, args) => {
    if let Expr::Attr(parent, member) = &callee.node {
        if let Expr::Ident(p) = &parent.node && p == "Option"
            && (member == "Some" || member == "None") { ... emit_option_constructor }
        if let Expr::Ident(p) = &parent.node && p == "Result"
            && (member == "Ok" || member == "Err") { ... emit_result_constructor }
        if let Expr::Ident(p) = &parent.node && p == "List"
            && member == "prepend" && args.len() == 2 { ... emit_list_prepend }
        // ... List.empty, user variant lookup via registry.variant_in, dotted builtin
    }
    // regular fn call
}
Expr::Constructor(name, payload) => { emit_constructor(...) }
Expr::TailCall(boxed) => { emit_tail_call(target, args, ...) }
```

After resolution this whole tree collapses to a clean three-way split:

```rust
ResolvedExpr::Ctor(ctor, args) => match ctor {
    ResolvedCtor::Builtin(BuiltinCtor::OptionSome) => emit_option_constructor(Some(&args[0]), None, ...),
    ResolvedCtor::Builtin(BuiltinCtor::OptionNone) => emit_option_constructor(None, Some(&hint), ...),
    ResolvedCtor::Builtin(BuiltinCtor::ResultOk) => emit_result_constructor("Ok", args.first(), ...),
    ResolvedCtor::Builtin(BuiltinCtor::ResultErr) => emit_result_constructor("Err", args.first(), ...),
    ResolvedCtor::User { type_id, name, .. } => {
        // Look up variant_info via registry (need TypeId → canonical type name conversion;
        // ctx.symbol_table.type_entry(*type_id).key.canonical() does this)
        emit_constructor_with_args(...)
    }
    ResolvedCtor::Unresolved { name } => return Err(...),
},
ResolvedExpr::Call(callee, args) => match callee {
    ResolvedCallee::Builtin(name) => {
        // "List.prepend" / "List.empty" / dotted builtin special cases
        if name == "List.prepend" && args.len() == 2 { return emit_list_prepend(...); }
        if name == "List.empty" && args.is_empty() { return emit_list_empty(...); }
        let (parent, member) = name.rsplit_once('.').unwrap();
        emit_dotted_builtin(parent, member, args, ...)
    }
    ResolvedCallee::Fn(id) => {
        let name = ctx.symbol_table.fn_entry(*id).key.canonical();
        let entry = ctx.fn_map.by_name.get(&name).ok_or(...)?;
        for arg in args { emit_expr(arg, ...)?; }
        func.instruction(&Instruction::Call(entry.wasm_idx));
    }
    ResolvedCallee::Intrinsic(intr) => {
        // __buf_* / __to_str — route to emit_dotted_builtin with intr.name() (legacy path
        // emitted them as bare Ident calls through the same builtin dispatch)
    }
    ResolvedCallee::LocalSlot { name, .. } => {
        // higher-order — wasm-gc emits Unreachable (validation-polymorphic)
        func.instruction(&Instruction::Unreachable);
    }
    ResolvedCallee::Unresolved { .. } => return Err(...),
},
ResolvedExpr::TailCall { target, args } => {
    let target_name = ctx.symbol_table.fn_entry(*target).key.canonical();
    emit_tail_call(func, &target_name, args, slots, ctx)?
}
```

**You'll need to thread `&SymbolTable` through `EmitCtx`** (currently it doesn't have it) so the FnId → canonical name conversion at the dispatch site works. The symbol table lives in `ctx.symbol_table` on `CodegenContext`; `body.rs::emit_fn_body` will receive it from `module.rs::emit_module` (which already has the codegen ctx in scope).

**Shape-aware sites that sed CAN'T handle** (~7 in `body/emit.rs`, similar count in `slots.rs` / `builtins.rs`):
- `Expr::FnCall(callee, args)` → `ResolvedExpr::Call(callee, args)` where `callee: &ResolvedCallee` (not `&Spanned<Expr>`). The dispatch on `&callee.node == Expr::Attr(...)` collapses — see the rewrite sketch above.
- `Expr::Constructor(name, payload)` → `ResolvedExpr::Ctor(ctor, args)` where `ctor: &ResolvedCtor`. `name: String` and `payload: Option<Box<Spanned<Expr>>>` collapse into `ctor` + `args: Vec<Spanned<ResolvedExpr>>`.
- `Expr::TailCall(boxed)` where `boxed.target: String`, `boxed.args: Vec<Spanned<Expr>>` → `ResolvedExpr::TailCall { target: FnId, args: Vec<Spanned<ResolvedExpr>> }`. Convert `FnId` → canonical name via `ctx.symbol_table.fn_entry(*target).key.canonical()`.
- `ResolvedPattern::Ctor(name: String, bindings: Vec<String>)` is now `ResolvedPattern::Ctor(ctor: ResolvedCtor, bindings: Vec<String>)`. The match-arm dispatch (lines ~1822, ~1895, ~2072, ~2178, ~2267, ~2527, ~2574, ~2643) needs the `name` extracted: for `ResolvedCtor::Builtin(BuiltinCtor::*)` produce the dotted string ("Option.Some" / "Result.Ok" / etc.); for `ResolvedCtor::User { name, type_id, .. }` produce the qualified name via `ctx.symbol_table.type_entry(*type_id).key.canonical() + "." + name`.

After running the sed, expect **~170 cascading compile errors** because `body/builtins.rs` and `body/builtins_wasip2.rs` take `args: &[Spanned<Expr>]` from `body/emit.rs` callers. Migrate them next (mostly mechanical — change signature + `.node` for accessing inner). The errors decrease as you cascade outward.

## Pitfalls I hit (don't repeat)

- **CI rustfmt vs local rustfmt disagree on short fn signatures.** CI collapses to one line, local wraps. After fmt, eyeball the diff; if you see multi-line single-arg fns, manually collapse. Same goes for short `use` lists.
- **`life.wasm` md5 is non-deterministic** across builds. The wasm-gc type registry uses a `HashMap` whose iteration order isn't stable, so the type-section byte order shifts. Size is deterministic. Don't waste time chasing a regression that isn't one — `wc -c` for `life`, `md5` for everything else.
- **`body/emit.rs` dispatch tree is the hard part.** Don't underestimate the restructuring of the `Expr::FnCall(Attr(Ident("Option"), member))` chain to `ResolvedExpr::Ctor(Builtin(...))`. The hand-coded recognition collapses into a clean `match ctor` block, but the rewrite is non-mechanical.
- **`builtins.rs` / `builtins_wasip2.rs` cascade together** — they all take `&[Spanned<Expr>]` args from emit.rs callers, and the signature change cascades. Plan to migrate all three files in the same commit.
- **`EmitCtx` doesn't currently have `symbol_table`** — you need to thread it through to do the `FnId` → canonical name conversion at the `Call(Fn(id), args)` dispatch site. `body.rs::emit_fn_body` signature gains a `symbol_table: &SymbolTable` parameter; `module.rs` callers pass `&ctx.symbol_table`.
